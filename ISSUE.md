
# Title

[Bug]: The transcription overrides any image copied to the clipboard. #35

# Description

### What happened?

Whenever I have an image copied to the clipboard and I dictate something to the app, when I go to Ctrl V the copied image is pasted instead of what I just said.

### Expected Behavior

I expected that when I pasted something, it would paste what I just copied instead of what I was saying to the app.

### Steps to Reproduce

1. Copy an image to the clipboard
2. Transcribe something with Dito
3. Ctrl V to paste

### Python Version

None

### Operating System

Windows 11

### Additional Context

This is not the case when I have a text copied to the clipboard. In that case, the app replaces what was just said and pasted with what was copied to the clipboard in the first place. But when I have an image copied to the clipboard, then the error happens.
